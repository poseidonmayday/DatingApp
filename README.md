
# DatingApp — приложение «Знакомства»

Учебный проект по объектно-ориентированному программированию на Java.

## Описание

Консольное приложение для работы с профилями пользователей,
их интересами, фотографиями, лайками и социальными связями.

Программа позволяет находить людей с общими интересами
и рекомендовать возможных знакомых через социальный граф.

## Возможности

- Регистрация и просмотр профилей пользователей.
- Хранение возраста, города и социальных контактов.
- Добавление интересов.
- Добавление фотографий и лайков.
- Создание двусторонних знакомств.
- Поиск общих знакомых.
- Фильтрация по возрасту и городу.
- Подбор пользователей по общим интересам.
- Рекомендации «Вы можете знать».
- Ведение журнала событий.
- Автоматическая симуляция с фиксированным seed.

## Технологии

- Java 23
- Maven
- JUnit 5
- IntelliJ IDEA

## Запуск

Запустить метод main() класса dating.Main
через IntelliJ IDEA.

При запуске без аргументов открывается консольное меню
с демонстрационными данными.

Для автоматической демонстрации можно указать аргументы:

--simulate 25

Для получения справки:

--help

После сборки JAR приложение запускается командой:

java -jar target/DatingApp-1.0-SNAPSHOT.jar

Имя JAR зависит от artifactId и version в pom.xml.

## Автоматическая симуляция

Класс DemoSimulator создаёт демонстрационный набор данных:

- 8 профилей;
- интересы и контакты;
- фотографии;
- двусторонние знакомства;
- лайки.

Используется java.util.Random с заданным seed.

Одинаковое значение seed позволяет воспроизводить
один и тот же сценарий.

## Тестирование

Для тестирования используется JUnit 5.

Тесты проверяют:
- корректность профилей и фотографий;
- ограничения и обработку ошибочных данных;
- лайки и двусторонние знакомства;
- фильтрацию и рекомендации;
- воспроизводимость симуляции;
- работу консольного интерфейса.

Запуск тестов:

mvn test

Или через Maven -> Lifecycle -> test в IntelliJ IDEA.

## Сборка

mvn clean package

Результат сборки находится в папке target.

## Особенности реализации

Логика приложения отделена от консольного интерфейса.

SocialGraph хранит двусторонние связи пользователей.

DatingService управляет данными, выполняет операции
и записывает события.

DemoSimulator создаёт тестовый сценарий.

Фотографии представлены идентификаторами и строковыми
путями. Загрузка реальных изображений не реализована.

Данные хранятся в оперативной памяти и не сохраняются
между запусками приложения.
